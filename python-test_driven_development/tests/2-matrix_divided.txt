The ``2-matrix_divided`` module
===============================

Using ``matrix_divided``
------------------------

Import the function from the module:

    >>> matrix_divided = __import__('2-matrix_divided').matrix_divided

A matrix of integers is divided and rounded to 2 decimals. The original
matrix is not modified:

    >>> matrix = [[1, 2, 3], [4, 5, 6]]
    >>> matrix_divided(matrix, 3)
    [[0.33, 0.67, 1.0], [1.33, 1.67, 2.0]]
    >>> matrix
    [[1, 2, 3], [4, 5, 6]]

Different kinds of matrices and divisors:

    >>> matrix_divided([[1.5, 3.0], [4.5, 6.0]], 3)
    [[0.5, 1.0], [1.5, 2.0]]
    >>> matrix_divided([[1, 2], [3, 4]], 0.5)
    [[2.0, 4.0], [6.0, 8.0]]
    >>> matrix_divided([[1, 2], [3, 4]], -2)
    [[-0.5, -1.0], [-1.5, -2.0]]
    >>> matrix_divided([[1, 2.5, 3]], 2)
    [[0.5, 1.25, 1.5]]
    >>> matrix_divided([[-1, -2], [3, -4]], 4)
    [[-0.25, -0.5], [0.75, -1.0]]
    >>> matrix_divided([[10]], 4)
    [[2.5]]
    >>> matrix_divided([[1, 2, 3]], 3)
    [[0.33, 0.67, 1.0]]
    >>> matrix_divided([[1, 2], [3, 4]], 1)
    [[1.0, 2.0], [3.0, 4.0]]
    >>> matrix_divided([[0, 0]], 5)
    [[0.0, 0.0]]
    >>> matrix_divided([[1, 2]], 1000)
    [[0.0, 0.0]]
    >>> matrix_divided([[1, 2]], 7)
    [[0.14, 0.29]]
    >>> matrix_divided([[10, 20, 30]], 3)
    [[3.33, 6.67, 10.0]]
    >>> matrix_divided([[5, 10]], 2.5)
    [[2.0, 4.0]]
    >>> matrix_divided([[10 ** 6, 2 * 10 ** 6]], 10 ** 6)
    [[1.0, 2.0]]
