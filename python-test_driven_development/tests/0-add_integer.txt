The ``0-add_integer`` module
============================

Using ``add_integer``
---------------------

Import the function from the module:

    >>> add_integer = __import__('0-add_integer').add_integer

Integers are added together:

    >>> add_integer(1, 2)
    3
    >>> add_integer(100, -2)
    98
    >>> add_integer(0, 0)
    0
    >>> add_integer(-1, -1)
    -2
    >>> add_integer(-5, 5)
    0

The second argument defaults to 98:

    >>> add_integer(2)
    100
    >>> add_integer(-98)
    0

Floats are cast to integers before the addition:

    >>> add_integer(100.3, -2)
    98
    >>> add_integer(1.9, 2.9)
    3
    >>> add_integer(-1.9, 0)
    -1
    >>> add_integer(2.5)
    100
    >>> add_integer(1, 2.7)
    3

Big numbers work:

    >>> add_integer(10 ** 20, 1)
    100000000000000000001
    >>> add_integer(-10 ** 20, 10 ** 20)
    0
