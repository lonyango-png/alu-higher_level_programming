# Python - Test-driven development

Python functions written test first: each function has its module and
function documentation, and an interactive doctest file (or a unittest
file for `6-max_integer.py`) in the `tests` folder.

Run the doctests with `python3 -m doctest -v ./tests/<file>.txt` and the
unittests with `python3 -m unittest tests.6-max_integer_test`.
